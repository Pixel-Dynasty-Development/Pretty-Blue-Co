# Pretty in Blue Website 👕

Welcome to the official repository for the **Pretty in Blue** website. This project serves as the digital storefront and portfolio for their custom apparel designs.

---

### 🚀 Overview
**Pretty in Blue** specializes in high-quality, custom-designed apparel. This website is built to showcase collections, handle custom order inquiries, and provide a seamless experience for clients.

### 🛠️ Tech Stack
* **Frontend:** [e.g., Vue.js / React]
* **Styling:** [e.g., Tailwind CSS]
* **Backend:** [e.g., Node.js / Express]
* **Infrastructure:** Docker

---

### 📂 Key Features
* ✨ **Dynamic Catalog:** Browse current apparel designs and limited drops.
* 📝 **Custom Order Form:** A streamlined interface for clients to submit specific design requests.
* 📱 **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
* ⚡ **High Performance:** Fast loading times for high-resolution product imagery.
